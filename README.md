# Alpwise – Android-App

Wanderungen in der Schweiz sicher planen: Routen, Wetter, Sperrungen, SOS und Offline-Karten.

**Download:** [alpwise.apk (neueste Version)](https://github.com/atieh-ros/Alpwise-App/releases/latest/download/alpwise.apk)

**Website:** https://alpwise-coral.vercel.app

## Installieren
1. `alpwise.apk` herunterladen und mit **Paketinstaller** öffnen.
2. «Unbekannte Apps installieren» für den Browser einmal erlauben.
3. **Installieren**. Warnt Play Protect: **Weitere Details → Trotzdem installieren**.

Nur Android. Auf dem iPhone die Website verwenden.

> Alpwise ist eine Planungshilfe und kann keine Sicherheit garantieren. Notfall: **Rega 1414** oder **112**.
